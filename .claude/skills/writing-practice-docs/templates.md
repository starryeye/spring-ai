# 템플릿

각 틀의 `<…>` 를 채운다. 절 제목 바로 위에는 다른 문서가 링크할 `<a id="…"></a>` 를 둔다. "원문 필드" 뒤의 N 은 정수 하나이고 표의 데이터 행 수와 같아야 하며, `check_docs.py` 의 `field-count` 규칙이 그 둘을 센다.
