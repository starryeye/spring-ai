===== P8. 응답에 refresh_token 이 없다 — Spring 은 공개 클라이언트에 발급하지 않는다 =====
응답 필드: access_token scope id_token token_type expires_in
OAuth2RefreshTokenGenerator.generate() 가 authorization_code 그랜트에서 클라이언트 인증 방식이
none 이면 null 을 돌려준다("Do not issue refresh token to public client").
OAuth 2.1 §4.3.1 은 공개 클라이언트에 대한 refresh token 발급을 MAY 로 두고, 발급한다면
회전 또는 sender-constrained 를 MUST 로 요구한다. 발급하지 않는 쪽은 명세 위반이 아니다.
대조 — 기밀 클라이언트의 토큰 응답 필드: access_token refresh_token scope id_token token_type expires_in
